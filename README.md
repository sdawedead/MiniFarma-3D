# MiniFarma 3D

An interactive 3D planning prototype for a compact self-sufficiency farm.

The scene is designed to experiment with the placement of growing beds, animals, paths, water systems and other small-farm elements before building them in the real world.

## Highlights

- Interactive Three.js scene
- Modular farm components
- Labels and layout helpers
- Responsive UI
- Vite / JavaScript project

## Stack

JavaScript, Three.js, Vite, HTML, CSS.
